# 0.1.0.000
## Added
* Basic **Level 0** Generation.
* **NoClip Event**. 
  * When you're inside a wall, you can leave reality and enter Level 0. 
  * There is a Gamerule to enable or disable spontaneous NoClip; in other words, it allows for the possibility of NoClip occurring randomly. 
  * With the “/noclip” command, you can travel between levels and realities.
